# ブルベ・イエベ判定アプリ（Personal Color Check）

顔写真から、パーソナルカラーの **イエベ（黄み）／ブルベ（青み）** を判定し、春・夏・秋・冬の4シーズンまで表示する、ブラウザだけで動く静的Webアプリです。

`index.html` をブラウザで開くだけで使えます。ビルドもサーバーも不要です。

## 使い方

1. `index.html` を開く
2. 顔写真を選ぶ（最大3枚まで追加できます）
3. 判定結果、信頼度、似合う色パレット、メイク・ファッションのアドバイスが表示されます

正確に撮るコツ：自然光・フィルターなし・薄メイク寄りの写真がおすすめです。

## 判定のしくみ

AIや顔認識モデルではなく、端末内での色測定です。

- 額・両頬・あご・鼻まわりなど部位別に肌ピクセルを測り、目・口・髪や影の影響を避けます
- 照明の色かぶり（蛍光灯・電球など）を推定して補正します
- 人の目に近い Lab 色空間で、黄み⇄青み（b*）、明るさ（L*）、鮮やかさ（C*）を測定し、外れピクセルは中央値＋trimmed平均で除去します
- 4シーズンは確率で表示し、イエベ／ブルベが中間寄りの場合はその旨と次点タイプも表示します
- 最大3枚の写真を平均化し、外れた1枚は自動で除外します

## プライバシー

- 写真は **端末（ブラウザ）内だけで処理** され、外部送信・保存はしません
- 通信が発生するのは Google Fonts の読み込みのみです（フォントを表示できない環境では代替フォントで表示されます）

## 注意（正確さについて）

- 本アプリは **目安** であり、プロの対面パーソナルカラー診断の代わりではありません
- プロ診断との照合による正解率の検証は行っていません
- 照明、ホワイトバランス、ファンデーション、フィルターによって結果は変わり得ます
